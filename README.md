# Text Mining

A collection of text mining and NLP utilities in Python.

## Getting Started

### Prerequisites

- Python 3.8+
- pip

### Installation

```bash
pip install -r requirements.txt
```

## Project Structure

```
text-mining/
├── data/        # Raw and processed datasets
├── notebooks/   # Jupyter notebooks for exploration
├── src/         # Source code
└── tests/       # Unit tests
```
